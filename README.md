# Dr. Sérgio Barrichello — Website Makeover

Modern, high-performance, **SEO & GEO optimized** website for **Dr. Sérgio Barrichello**, specialist in non-surgical weight loss (endoscopic bariatric procedures).

**Live preview (open the file):**  
https://github.com/josekommisar/dr-sergio-barrichello-makeover/blob/main/index.html

## Overview

This is a complete redesign focused on:

- **Technical SEO foundations** (semantic HTML, optimized title & meta, canonical, Open Graph, robots)
- **GEO (Generative Engine Optimization)** readiness with clear entity signals + Schema.org `Physician`
- **Performance** (lightweight, minimal JS, fast first paint)
- **Mobile-first** responsive design
- **Trust & conversion** oriented for a medical specialist (multiple WhatsApp CTAs + floating button)
- Clean medical aesthetic (teal primary + elegant typography)

## Tech Stack

- Pure **HTML5** + **Tailwind CSS** (CDN — easy to preview and convert later)
- Google Fonts (Inter + Playfair Display)
- Zero heavy frameworks
- Ready for static hosting (Vercel, Netlify, Cloudflare Pages, GitHub Pages, etc.)
- Easy to migrate later to Astro / Next.js / Remix if needed

## How to use

1. Open `index.html` directly in any modern browser
2. Replace the photo placeholder with a real professional image of Dr. Sérgio
3. Update the `canonical` URL and Open Graph image when deploying to the final domain
4. Deploy to any static host
